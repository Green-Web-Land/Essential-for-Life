# Curriculum

[Course home](README.md)

Standalone adult first edition, ages 18+. Learn with fictional work records, paper and an optional basic calculator. Being employed is not a prerequisite.

| Lesson | Observable learning evidence |
|---|---|
| [1. Understand your role](lessons/01-role.md) | Separate assigned work, authority and missing information. |
| [2. Clarify a task before committing](lessons/02-clarify.md) | Turn an ambiguous request into a checkable task agreement. |
| [3. Plan realistic work](lessons/03-plan.md) | Build a feasible schedule from durations and dependencies. |
| [4. Communicate useful progress](lessons/04-progress.md) | Write an update that distinguishes facts, uncertainty and decisions. |
| [5. Collaborate and hand over](lessons/05-handoff.md) | Provide enough context for another person to continue. |
| [6. Check quality and handle mistakes](lessons/06-quality.md) | Report a discrepancy and propose a bounded correction. |
| [7. Learn from feedback](lessons/07-feedback.md) | Convert specific feedback into a practical learning step. |
| [8. Respect people and information](lessons/08-respect.md) | Choose an action that fits permissions and access needs. |
| [9. Raise concerns and find support](lessons/09-concerns.md) | Distinguish a routine work question from a safety or rights concern. |
| [10. Final fictional work assignment](lessons/10-project.md) | Produce a feasible plan, honest update and usable handoff. |

## Sequence and assessment

Lessons 1–3 establish role, scope and a feasible plan. Lessons 4–6 connect progress, handoff and quality. Lessons 7–9 cover learning, respectful information handling and concerns. Lesson 10 combines these skills with a changed priority and a corrected draft.

Every lesson contains a worked example, practice task, suggested reasoning and a new situation. Return to an earlier lesson when helpful; do not turn the sequence into a prerequisite for seeking support.

Assess reasoning against the stated fictional facts. Check timing with the assumptions supplied, permission boundaries and distinctions between sent, usable and approved. Use the [rubric](FACILITATOR-GUIDE.md) for feedback and revision; it is not an employee performance instrument or professional certification.

## Scope

Skills practice does not replace workplace orientation, competent safety training, access approvals or local legal guidance. Changes to audience, actual data collection or real workplace decision-making require assessment of that activity.
