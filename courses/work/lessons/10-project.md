# 10. Final fictional work assignment

[Course home](../README.md) · [Glossary](../GLOSSARY.md)

**Goal:** Produce a feasible plan, honest update and usable handoff.

Adults 18+. All workplaces, people, policies and task timings in these exercises are fictional. Work on paper; no real workplace access or disclosure is required.

## Understand

Use only the supplied fiction and a paper clock or basic calculator. One worker performs tasks sequentially; estimates are fixed teaching inputs for this exercise. No multitasking, omitted checks, extra worker or additional work hours may be assumed.

You will revise a plan as facts change. A draft, a checked draft, an approved document and a received handoff remain different states. A corrected plan must name its assumptions, not simply replace an inconvenient deadline with a later one.

## Worked example

Mini-example: a draft needs 20 minutes and its check needs 10 minutes afterwards. Starting at 10:00 gives a checked draft at 10:30, not 10:20. If the source is unavailable until 10:15, earliest completion is 10:45. The work still takes 30 minutes; waiting changes elapsed time.

## Practise

Full scenario, same day and local time: Noor has a reserved work window 09:00–12:00. Pat asks for a stock-summary draft. Clarification takes 15 minutes from 09:00. Pat confirms three required sections, preservation of source numbers and no external sending. Source data arrives at 09:30. Drafting takes 35 minutes, checking takes 20 minutes, and internal handoff takes 10 minutes after checking. Original handoff deadline: 11:00.

1. Record the clarified output, quality criteria and permission limit. Name two remaining practical questions.
2. Build the earliest schedule, including waiting. Calculate effort, elapsed time from 09:00 and margin before 11:00.
3. At 10:05, after drafting, Pat requests an urgent 30-minute task before checking. Calculate the new finish and report the deadline conflict before promising both.
4. Pat explicitly confirms the urgent task goes first and revises handoff deadline to 11:20. During checking, Noor finds a duplicate row. Correction plus recheck requires an additional 10 minutes. Recalculate and write an update.
5. Prepare the handoff identifying the corrected version, checks and review still pending. The recipient confirms the file opens but gives no approval. State what this establishes.
6. Explain the next step if the required source instead contained records you were not authorized to use; do not copy or upload real records.

## Suggested reasoning

Baseline: clarify 09:00–09:15; wait 09:15–09:30; draft 09:30–10:05; check 10:05–10:25; handoff 10:25–10:35. Effort is 80 minutes, elapsed time 95 minutes and original deadline margin 25 minutes. Remaining questions can concern the internal reviewer, required file format or approved storage location.

With the added urgent task: urgent work 10:05–10:35; check 10:35–10:55; handoff 10:55–11:05. This is five minutes after the original deadline, so Noor must request a decision. Pat's explicit change makes 11:20 the revised deadline; Noor cannot make that change unilaterally.

With correction: check 10:35–10:55; correct and recheck 10:55–11:05; handoff 11:05–11:15. Total effort is 120 minutes; elapsed time from 09:00 is 135 minutes. Margin before the revised 11:20 deadline is five minutes.

Possible update during checking: “Draft and urgent task complete. I found a duplicate row; correction and recheck add ten minutes. Estimated handoff is 11:15 against the revised 11:20 deadline, with review still pending.” Handoff names stock-summary draft v2, the permitted source, the duplicate-row correction and the check results, then asks Pat for review. An “opens correctly” response confirms usability, not acceptance. With unauthorized source data, pause that use and ask the authorized contact for a permitted input or access decision; do not bypass the restriction.

## Try a new situation

Transfer: a later input shifts the baseline source arrival to 09:45. Ignore the urgent task and correction in this separate variation. Recalculate: draft 09:45–10:20; check 10:20–10:40; handoff 10:40–10:50. Effort remains 80 minutes including clarification; elapsed time becomes 110 minutes; margin before 11:00 is ten minutes. Explain why a later input changes the schedule without increasing the task effort.
