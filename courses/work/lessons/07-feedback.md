# 7. Learn from feedback

[Course home](../README.md) · [Glossary](../GLOSSARY.md)

**Goal:** Convert specific feedback into a practical learning step.

Adults 18+. All workplaces, people, policies and task timings in these exercises are fictional. Work on paper; no real workplace access or disclosure is required.

## Understand

Feedback is more usable when it identifies an example, a criterion and a possible next step. If the comment is vague, ask what change would meet the requirement. You can check understanding without agreeing to an unsupported personal judgement.

For these exercises, separate a description of the work from an insult about the person. “The handoff does not identify the version” points to a correctable feature. “You are useless” does not explain how to improve the output. The CCOHS reference in Sources discusses bullying and reasonable work direction; this course does not decide whether a real incident meets a legal definition.

Try one small change, compare the result with the criterion, and ask for review where appropriate. A practice target is not a promise that you will never make another mistake.

## Worked example

Pat says Noor's update did not name the blocked task. Noor asks, “Would naming the missing page and the check it prevents meet the requirement?” Pat confirms. Noor adds that information and uses a short checklist for the next update. This response tests an observable change rather than guessing what “be more professional” means.

## Practise

A draft receives “too confusing.” Write two neutral questions to obtain useful detail, and a practice action that depends on the answer.

## Suggested reasoning

Ask which passage is confusing and what the intended reader needs to find. A suitable action is to rewrite that passage with the confirmed requirement first, then ask whether the revision answers it. Do not rewrite everything without knowing the problem or claim the reader must be wrong.

## Try a new situation

A fictional reviewer makes repeated personal insults instead of discussing the work. Explain why asking for a clearer paragraph is not the only possible next step. Check that your answer includes an appropriate support route from lesson 9 rather than diagnosing the reviewer.
