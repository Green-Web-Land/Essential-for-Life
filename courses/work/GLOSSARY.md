# Glossary

[Course home](README.md)

Working educational meanings, not legal definitions.

| Term | Meaning in this course |
|---|---|
| Role | The work and responsibilities assigned in the scenario. |
| Authority | Permission to make a particular decision or take an action. |
| Deliverable | The output requested, such as a draft or checked table. |
| Scope | What the task includes and excludes. |
| Completion criterion | A condition used to check whether the requested output is complete. |
| Dependency | Something needed before a task can proceed. |
| Effort | Time spent working on a task. |
| Elapsed time | Time from a stated start to finish, including waiting. |
| Margin | Time between planned finish and the stated deadline. |
| Estimate | A forecast based on assumptions; not guaranteed. |
| Blocker | A missing condition preventing the next required step. |
| Risk | Something that may affect the work but has not necessarily happened. |
| Handoff | Transfer of work and context for another person's next action. |
| Receipt | Evidence an item arrived; not necessarily proof it works. |
| Usability | The recipient can access and use the item for the stated purpose. |
| Acceptance | A responsible person confirms the required review or decision. |
| Quality check | Comparing an output with requirements and source evidence. |
| Recheck | Checking affected work again after a correction. |
| Feedback | Information about work that can guide improvement. |
| Jurisdiction | The legal authority or coverage relevant to a situation. |
| Designated contact | The person or service identified for a particular kind of issue. |
| Confidentiality | Limits on sharing information; do not assume an absolute promise. |
