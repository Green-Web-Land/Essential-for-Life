# 7. Check, repeat and correct

[Course home](../README.md) · [Glossary](../GLOSSARY.md)

**Goal:** Distinguish rechecking an analysis from collecting new evidence.

Adults 18+. All named people, examples, role cards and datasets are fictional. Use paper or an accessible equivalent; a calculator is optional.

## Understand

The National Academies' public explainer distinguishes redoing an analysis with the same data from examining the question with newly collected data. In this course we call the former reproducibility and the latter replication. Terminology differs across fields, so state which operation you mean.

Agreement can increase confidence without proving a result universally. Disagreement can arise from different methods, conditions, variation or mistakes; it does not by itself prove fraud. A result with no clear difference can still be informative, but is not automatic proof that no effect exists.

To help checking, keep data, analysis steps and corrections understandable, subject to privacy, permissions and other applicable limits. Transparency is not permission to expose private records.

## Worked example

Fictional totals for 8, 10 and 12 cm were reported as 33 cm. Recalculation gives 30 cm and mean 10 cm. Correct the summary and explain the arithmetic error while retaining the original readings. This is a same-data check, not new measurement evidence.

## Practise

Classify: A recalculates a table using its original values; B uses newly supplied fictional observations to compare the same question; C copies the old conclusion without checking. Which adds a same-data check, which represents a new-data check, and which does neither?

## Suggested reasoning

A checks the existing calculation. B represents replication in the stated vocabulary, though fictional data are not real empirical replication. C supplies no new check. Describe methods and differences before deciding whether results conflict.

## Try a new situation

A fictional comparison finds similar values in two small groups. Rewrite “There can never be any difference.” Check: say no clear difference was established in this dataset and identify the design and evidence needed for a broader claim.
