# Becoming a Scientist — glossary

[Course home](README.md)

Plain-language meanings used in this course. Technical vocabulary can differ by field; state the operation you mean.

| Term | Meaning here |
|---|---|
| Observation | A recorded feature, event or instrument reading, with a method and possible limitations. |
| Hypothesis | A proposed explanation that can be examined using evidence. |
| Prediction | A result expected under stated conditions if an explanation is useful. |
| Evidence | Information used to assess a claim; its quality and relevance matter. |
| Variable | A feature that can differ among observations or conditions. |
| Independent variable | The factor varied in the simple experiment model used here. |
| Dependent variable | The recorded outcome in that model. |
| Controlled condition | A condition intended to remain comparable. |
| Confounding | A competing factor that changes along with the factor of interest and limits interpretation. |
| Association | A pattern connecting variables, without by itself establishing a cause. |
| Unit | A specified scale of measurement, such as centimetres or seconds. |
| Resolution | The level of detail an instrument or record can distinguish; not a complete uncertainty assessment. |
| Bias | A systematic tendency that can affect measurement or inference. |
| Mean | Sum of the values divided by their count. |
| Observed range | Maximum minus minimum in the listed values. |
| Uncertainty | A limit to what the evidence establishes; measurement uncertainty has more specific technical definitions. |
| Reproducibility | Here, checking an analysis with the same data and specified methods. |
| Replication | Here, examining a question with newly collected data; fictional exercises only illustrate this. |
| Research ethics review | Assessment by the responsible body under applicable rules; this course does not provide it. |
| Fictional dataset | Invented values openly labelled for teaching, not evidence of a real study. |
