# Developer reuse guide

[Course home](README.md)

Copy this complete folder at a recorded revision, including lessons, sources, figures and licence. No other course or live GitHub dependency is required for the required activities.

Preserve stable lesson paths, headings, tables, alt text and adjacent image explanations. Keep fictional labels, adult audience and optional participation visible. SVG files are editable originals; PNGs are display copies. Figures contain no scripts or external images.

When adapting scenarios, recheck facts, answer guidance and consent implications together. Do not turn the rubric into a relationship risk score, diagnostic assessment or judgement of a real family. Do not remove the distinction between ordinary disagreement and threats while retaining the original answer.

Static files collect no learner responses. Adding saved journals, chat, uploads, tracking, automated advice or crisis detection changes the reviewed activity. Assess privacy, security and suitability for the actual implementation; never describe a prompt instruction as a data safeguard.

Provide an offline reading route. Test keyboard access, resizing, contrast, image alternatives and screen-reader structure in your own renderer. Source figures and text alternatives do not establish formal accessibility conformance.

Follow [the licence](LICENSE.md), retain notices and identify changes. Check dated help links when maintaining an edition. The publisher's internal approval process is not an additional restriction on recipients' CC BY 4.0 rights.
