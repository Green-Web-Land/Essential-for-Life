# Glossary

[Course home](README.md)

These are working educational meanings, not legal or clinical definitions.

| Word | Meaning here |
|---|---|
| Assumption | Something treated as true without enough information in the scenario. |
| Fact | Information explicitly supplied for an exercise; real claims may still need checking. |
| Interpretation | A meaning someone gives to an event. More than one may be possible. |
| Understanding check | A brief summary offered for correction. |
| Request | A proposed action that allows a response, including refusal. |
| Demand | An insistence presented without a meaningful choice. |
| Boundary | A limit about one's participation, availability, possessions or information. |
| Consent | Permission for the specific everyday action being discussed; legal rules vary by context. |
| Privacy | Control and care concerning personal information and access; not a promise of absolute secrecy. |
| Capacity | What someone says they can practically do in the circumstances. |
| Shared responsibility | Work allocated through discussion and agreement in these exercises. |
| Coordination | The planning, checking and communication needed for tasks to fit together. |
| Contingency | An alternative to consider if a plan cannot proceed as expected. |
| Disagreement | Different views or preferences; it does not excuse threats or harm. |
| Coercive control | A pattern of behaviour restricting another person's freedom; see the PHAC reference in Sources. |
| Repair | A practical response to an action's effects; it cannot compel forgiveness. |
| Follow-through | Doing what was agreed, or addressing why it could not be done. |
| Support route | A type of person or service suitable for a concern; not a guarantee of access. |
| Reconciliation | Resuming or rebuilding a relationship; never a required exercise outcome. |
| Unknown | Information the exercise has not provided. It is acceptable to name it. |
