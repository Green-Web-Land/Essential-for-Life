# Everyday Personal Care — illustration provenance

[Course home](README.md)

Five original code-authored diagrams were created with AI assistance for this edition. Each is supplied as an editable SVG and a PNG rendering. No third-party photograph, logo, standardized care symbol or anatomical image is incorporated. No real person or health record is depicted.

| Files in images/ | Meaning |
|---|---|
| routine.svg / routine.png | Editorial planning sequence: purpose, resources, unknowns, manageable plan. |
| labels.svg / labels.png | Editorial prompt to identify a product, read directions, notice warnings and clarify gaps. |
| hands.svg / hands.png | Short visual paraphrase of PHAC handwashing guidance mapped in SOURCES.md. |
| laundry.svg / laundry.png | Editorial task organization; the fictional garment's actual directions still matter. |
| help.svg / help.png | Examples of practical access questions versus individual care questions, not triage. |

Every lesson image has alt text and an adjacent text equivalent. The diagrams were visually inspected; formal accessibility conformance and learner comprehension have not been tested. Edit both image and text if meaning changes.

Original contributions are offered under [the course reuse terms](LICENSE.md) to the extent the publisher holds rights. No assumption is made that every AI-assisted element independently attracts copyright. Third-party references retain their own rights.
