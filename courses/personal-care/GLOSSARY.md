# Everyday Personal Care — glossary

[Course home](README.md)

These are plain-language meanings for the lessons, not clinical definitions.

| Term | Meaning here |
|---|---|
| Access | Being able to obtain or use a needed space, supply or readable instruction. |
| Adaptation | A change made to suit a situation; clinical instructions may need professional clarification before changes. |
| Assistance | Help with an agreed task, with the person's permission. |
| Assumption | Something treated as true without confirmation. |
| Care label | Directions attached to an item about looking after it. |
| Dignity | Treating a person as worthy of respect, regardless of appearance or resources. |
| Dry flat | A fictional label direction requiring a suitable flat drying arrangement, rather than a tumble dryer. |
| General guidance | Broad information that does not assess a particular person. |
| Grooming | Everyday care choices involving hair, nails or appearance. |
| Individual instruction | Advice intended for a particular person's needs by a relevant professional. |
| Intended use | What a product's directions say it is for. |
| Prerequisite | Something needed before an action can reasonably proceed. |
| Privacy | Control over personal information and personal space in these exercises. |
| Qualified professional | A person with appropriate training and authority for the actual question; qualifications and access vary locally. |
| Rest opportunity | Time and conditions planned for rest; it does not guarantee sleep. |
| Routine | A recurring arrangement of everyday activities, with room for changing needs. |
| Source | The reference supporting a factual statement. |
| Unknown | Information the scenario does not provide. |
