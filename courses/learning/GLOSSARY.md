# How to Learn and Check Information — glossary

[Course home](README.md)

| Term | Meaning here |
|---|---|
| Association | A relationship in observed data; it does not by itself establish a cause. |
| Baseline | The stated reference used for a comparison. |
| Causal claim | A claim that one factor produces a change in another. |
| Claim | A statement that can be examined for meaning and support. |
| Correction | A revision to a record or explanation; identify what changed. |
| Count | Number of events or items meeting a stated definition. |
| Denominator | The total used as the reference in a fraction or rate. |
| Evidence | Information relevant to assessing a claim, with context and limitations. |
| Feedback | Information about a response that can help identify what to inspect or revise. |
| Hypothetical | Imagined for discussion, not represented as an observed fact. |
| Independent source | For a particular claim, a source with its own evidence rather than only repeating another report. |
| Learning goal | A selected task and an appropriate way to check progress. |
| Numerator | The counted part in a fraction. |
| Percentage | A proportion expressed per hundred. |
| Percentage-point difference | The subtraction of two percentage values. |
| Population | The people or items a claim concerns; a sample may not represent them all. |
| Proportion | A part divided by its relevant whole. |
| Recall | Bringing information to mind; distinguish it from reading an answer. |
| Relative change | Change divided by a stated baseline, often expressed as a percentage. |
| Retrieval practice | An attempt to recall learned material as part of practice. |
| Scope | What a claim covers, including people, task, place and period. |
| Self-selection | Participants choose their own group, which can complicate group comparisons. |
| Spacing | Returning to material across separate sessions. |
| Transfer task | A new example used to check application beyond the worked one. |
| Uncertainty | What cannot yet be established, and why. |
| Worked example | A demonstrated answer with its reasoning. |

These are introductory meanings for the course, not exhaustive specialist definitions.
