# Social Media glossary

[Course home](README.md)

| Term | Meaning here |
| --- | --- |
| Audience | People intended to receive content; copies may reach others. |
| Authentication | Checking a claim to an account identity. |
| Block | A service-specific restriction on an account's interaction; effects vary. |
| Caption | Text accompanying media; it can change the apparent context. |
| Consent | Clear agreement to a specified use in our respectful-sharing exercises; not a universal legal definition. |
| Context | Surrounding information such as date, place, purpose and original wording. |
| Copyright | Rights in qualifying creative expression; applicable rules and exceptions depend on law. |
| Credit | Identifying a source or creator; not automatically permission to reuse. |
| Digital footprint | Information left through online activity. |
| Disclosure | Making relevant information, such as a promotional relationship, apparent. |
| Disinformation | False information deliberately intended to mislead; intent should not be guessed. |
| Feed | An arranged selection of posts or other material. |
| Impression | A display-related metric whose exact definition varies by service; not proof of agreement. |
| Licence | Permission to use material under stated conditions. |
| Material connection | In the cited Canadian advertising context, a connection that can affect perceptions of independence. |
| MFA | Multi-factor authentication, using additional identity factors. |
| Misinformation | Incorrect information, without necessarily establishing deliberate intent. |
| Mute | A service-specific way to reduce what you see or hear; not necessarily an access restriction. |
| Permission setting | A technical control over some access or action, not proof of consent or legal rights. |
| Phishing | A deceptive attempt to induce disclosure or another risky action. |
| Provenance | Information about where material came from and its history. |
| Recommendation | Content selected or suggested by a service. |
| Report | A request for a service or authority to review an issue; not a guaranteed outcome. |
| Reshare | Distributing existing content to another audience. |
| Signal | An input used by a system; its weight and purpose can vary. |
| Sponsored content | Content connected to paid or other promotional arrangements. |
| Tag | A reference associating an account or label with content; behaviour varies. |

Definitions are introductory. See [Sources](SOURCES.md) for important external claims and their scope.
