# Computers: Understand and Use Them

A practical first course for adult beginners (18+). Learn what a computer does, choose tools, organise files and solve small problems while keeping control of your work. No previous computer knowledge is assumed. The audience designation is an editorial choice, not a tested age-suitability rating.

## Start here

Read one lesson at a time. Each includes an explanation, fictional example, practice, suggested reasoning and a new situation to try. You can complete the course on paper. Optional Windows 11 activities require only a device you are allowed to use and an existing text editor; no purchases, new accounts, installations or AI services are required. Stop if a task would overwrite real work, change someone else's settings or require permissions you do not have.
