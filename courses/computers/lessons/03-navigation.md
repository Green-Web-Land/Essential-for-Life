# 3. Getting around comfortably

[Course home](../README.md) · [Curriculum](../CURRICULUM.md) · [Glossary](../GLOSSARY.md)

**Objective:** Choose a way to navigate and identify where an action will happen.

A pointer helps you select items. Keyboard focus identifies the control that will receive keyboard input. A text cursor marks a position within editable text. These can appear together, but they mean different things.

Selecting a file is different from opening it. A button may act immediately; a menu may show choices first. Before acting, read the label and identify the current window. If a dialog asks you to replace, delete or grant access, pause until you understand its scope.

For a Windows 11 example, Windows key + E opens File Explorer. Tab commonly moves focus between controls and Shift + Tab moves back; exact behaviour depends on the application. These are optional examples, not requirements to change your device.

Windows also offers tools for access needs. Microsoft's current guidance documents Windows key + Plus to start Magnifier and Windows key + Esc to stop it. You can read about these controls without enabling them. If using someone else's computer, discuss preferences with its owner.

Choosing a larger view, a keyboard route, speech support or assistance is a practical choice. There is no prize for using the smallest text or the fastest pointer.

## Practise

Paper route: draw a window with a document area, a Save button and a Cancel button. Mark where keyboard focus is and where the text cursor is. Explain what pressing a key might affect.

Optional device route: on a computer you are allowed to use, open a familiar empty application and identify its title, menu and close control without changing settings or files. Stop if the screen does not match what you understand.

## Suggested reasoning

The text cursor belongs in the editable document; focus could instead be on a button. A typed letter and a command key may do different things depending on focus. Identifying the active window first helps prevent acting on the wrong material.

## Try a new situation

Explain how you would help someone who cannot comfortably use a mouse, without assuming which alternative suits them.
