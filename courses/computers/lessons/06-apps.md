# 6. Choose an application for the task

[Course home](../README.md) · [Curriculum](../CURRICULUM.md) · [Glossary](../GLOSSARY.md)

**Objective:** Explain why a tool fits a task and what information it would need.

A browser is an application used to access websites and web applications. A search engine is a service that helps find information. An address bar may accept both an address and search words, which can make these roles look the same.

Some applications work with files on a device; others use a service elsewhere; many do both. A familiar-looking document editor is not evidence that its contents stay only on your computer. Check the actual application and its settings before handling sensitive information.

Choose the task before the tool. A calculator may be suitable for a small sum, a text editor for a simple note, and a spreadsheet for a table with repeated calculations. AI is optional and is not required to complete this course. A convincing output still needs checking.

A download is not automatically trustworthy because it appears near the top of a search. Use the recognised publisher's route or the device owner's approved source, and check what you are being asked to install. This course does not ask you to install anything.

## Practise

For each fictional task, choose an available tool or a paper method and explain the reason:
- Add the costs 4, 7 and 9.
- Write a three-line invitation.
- Make a small table that totals several rows.
- Find the organiser's confirmed event time.

For the last task, state where confirmation must come from. Do not use a real event or account for the exercise.

## Suggested reasoning

The sum is 20 and can be checked manually or with a calculator. A text editor can handle the invitation. A spreadsheet can help with repeated totals, but formulas need checking. A confirmed event time needs the organiser's reliable information; a tool's confident guess is insufficient. More than one tool can suit a task.

## Try a new situation

A website asks for your contact list to make a blank invitation. Is the list necessary? Explain a way to complete the task with invented details instead.
