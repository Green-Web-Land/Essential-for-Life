# 5. Create, save and find your work

[Course home](../README.md) · [Curriculum](../CURRICULUM.md) · [Glossary](../GLOSSARY.md)

**Objective:** Create a fictional document and verify that you can find the saved file.

Saving deserves an explicit check. An application may preserve a tab or recover work, but that is not the same as knowing where your intended file is. Auto-save behaviour varies by application and location.

Our fictional text is:

> Practice only  
> Community reading table  
> Bring paper and pencils.

Choose the paper route if you do not have permission to create local practice files or cannot identify a suitable folder. Do not use Desktop or Documents as proof of local-only storage: they may be connected to a sync service.

The optional Windows 11 example uses an already available text editor, such as Notepad, and File Explorer. It does not require downloading software, enabling backup or creating an account. Menus can differ by application version.

## Practise

**Paper route:** write the supplied text on a card. Label an envelope Computer Practice and another Drafts inside it. Record a file name, reading-table.txt, and its complete intended location. Close the envelope, then locate the card again.

**Optional computer route:**
1. With the device owner's permission, identify an existing writable practice location whose sharing/sync status you understand. Create a fresh Computer Practice folder; if that name exists, choose another new name rather than merge.
2. Open an available text editor and enter the fictional text.
3. Use its File menu and Save As command to select the practice folder and the name reading-table.txt. Select a plain-text format if offered. Cancel any overwrite prompt.
4. In File Explorer, navigate to the chosen folder and locate the file. Use the editor's Open command to open that exact path and compare its contents.
5. Record the path on your worksheet. Leave the practice files in place until the device owner decides what to keep.

If you cannot identify the location or the application asks for sign-in, payment or installation, stop and use the paper route.

## Suggested reasoning

Success means finding the intended file at the recorded location and reading the supplied text from it. A restored tab alone does not establish that. Unexpected text or an overwrite prompt means stop and check the file name and folder; do not replace something to make the exercise pass.

## Try a new situation

How would you save a second version without replacing the first? Propose a new name and explain how you would verify which version you reopened.
