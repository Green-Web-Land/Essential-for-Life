# 10. Bring the skills together

[Course home](../README.md) · [Curriculum](../CURRICULUM.md) · [Glossary](../GLOSSARY.md)

**Objective:** Explain a complete fictional file workflow and how you would check it.

Your project is a fictional community reading table. The organiser needs a short invitation and a record of what to bring. Use invented details only. You can complete everything on paper; optional file creation uses only the permitted practice location from lesson 5.

The supplied facts are: the activity is fictional, bring paper and pencils, and the time has not yet been confirmed. Do not invent a confirmed time. Your output should make that uncertainty clear.

Create a small package someone else could understand without you standing beside them. A neat layout is helpful, but correctness, clear locations and safe decisions matter more than decoration.

## Practise

Produce these eight items:
1. Explain input, processing, output and storage for your invitation.
2. Choose a tool and a workable paper alternative.
3. Draw a folder arrangement with Drafts and Ready.
4. Write the invitation using only the supplied facts and mark the time unconfirmed.
5. Give a file name and location; explain how to save and reopen that exact file.
6. Describe what a recovery copy should protect against and how to check it without deleting the original.
7. Write one permission boundary for a shared computer.
8. Draft a short problem report for a fictional missing practice file.

Use your own wording. If working with files, do not send invitations, create accounts or enable services.

## Suggested reasoning

A worked outline: keyboard input becomes document text; saving writes a file; the screen displays it. A text editor or paper works. Drafts/invitation.txt contains “Time to be confirmed.” Reopening that path checks the saved text. Ready is reserved for material whose details have been checked, so this draft should not be represented as final.

A recovery plan should identify a separately retained copy, the version it contains and a non-overwriting check. A permission boundary might prohibit installation or changes outside the practice folder. A support note could state the expected path, what appeared and the location checks already tried.

Compare your work with these questions: are all eight items present? Are unconfirmed facts labelled? Can another reader identify the file? Are copying and independent backup distinguished? Have you avoided real data and unauthorised actions? Revise any missing part. These are discussion checks, not a certification exam.

## Try a new situation

Adapt the project to an invented gardening club. Explain what stays the same and what changes. Try this without copying the worked outline, then discuss your reasoning with a supporter if available.
