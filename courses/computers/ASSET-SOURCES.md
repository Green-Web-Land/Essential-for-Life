# Diagram sources

[Course home](README.md)

Five original code-authored teaching diagrams, prepared for Massoud Fattahi's Computers course on 11 September 2026. No vendor screenshots or third-party image assets are included. PNG reading copies and editable SVG sources share the course's [CC BY 4.0 notice](LICENSE.md).

| Asset | Purpose | Limits |
|---|---|---|
| information-flow.png / .svg | Input, processing, output and storage | Functional model, not wiring. |
| layers.png / .svg | Application, operating system and hardware | Simplified relationship, not every implementation. |
| folders.png / .svg | Same filename in separate folders | Fictional locations. |
| backup.png / .svg | Save, sync and retained recovery copy | No guarantee of any product's retention. |
| troubleshooting.png / .svg | Observe, protect, test and verify | Stop when consequences or authority are unclear. |

Each illustration has alternative text, a caption and a text equivalent in its lesson. Rendering checks assess this edition's visual layout; they do not establish accessibility of a future application.
