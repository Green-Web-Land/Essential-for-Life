# Curriculum

[Course home](README.md)

Audience: adult beginners, 18+. Prerequisites: none. Delivery: self-study or supported learning, with a paper route throughout. Optional device examples target Windows 11; interfaces may differ. Choose a pace that permits practice and breaks rather than treating speed as success.

## Review your progress

After each practice, compare your reasoning with the guidance. A different answer can be reasonable if you explain the assumptions. Revisit unclear terms in the glossary. Ask a supporter to explain an unfamiliar instruction without taking control of your account or asking for a password.

For the final project, check that you can: explain computer roles; select an appropriate application; distinguish two file locations; save and reopen a fictional file or describe the paper equivalent; distinguish sync from backup; recognise permission boundaries; and report an observed problem without inventing its cause.

Mark each skill “can explain”, “can demonstrate with guidance” or “can demonstrate independently”. These are personal learning notes, not a graded certification. Paper completion demonstrates conceptual reasoning; it does not establish practical device proficiency. The final project's worked outline provides a comparison, not the only acceptable design.
