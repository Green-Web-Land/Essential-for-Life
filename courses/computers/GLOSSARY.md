# Glossary

[Course home](README.md)

| Term | Meaning in this course |
|---|---|
| Account | An identity used to access a device or service; different services can have separate accounts. |
| Application | Software used for a task, such as writing or calculating. |
| Backup | A retained copy intended to support recovery when working information is lost or damaged. |
| Browser | An application for accessing websites and web applications. |
| Cloud storage | Storage operated through a remote service; its access and retention depend on that service and configuration. |
| Copy | Make another instance of a file; check where both are stored. |
| Cursor | A position indicator; a text insertion cursor differs from a pointer. |
| Extension | A filename suffix commonly associated with a format; renaming it does not convert content. |
| File | A named unit of stored information. |
| Focus | The interface element currently receiving keyboard input. |
| Folder | A container used to organise files and other folders. |
| Hardware | Physical computer equipment. |
| Input / output | Information supplied to / presented by a computer system. |
| MFA | Multi-factor authentication: using more than one type of evidence to sign in. |
| Operating system | Software that manages device resources and provides services to applications. |
| Path | A description of a file or folder's location. |
| Permission | Authority granted to access information or perform an action. |
| Processor | Hardware that executes operations. |
| RAM | Working memory used while programs run; distinguish it from retained file storage. |
| Restore | Recover information from an available retained copy. |
| Search engine | A service that helps find information; commonly accessed through a browser. |
| Shortcut | A reference to a target; not necessarily a copy of the target file. |
| Software | Programs and instructions used by a computer. |
| Sync | Keeping selected locations in step; changes, including deletion, can propagate. |
| Update | A software change that may fix faults, address security issues or change features. |
