# Exploring the Cosmos — developer guide

[Course home](README.md)

Copy the complete folder, including lessons, figures, source notes and licence. Pin the approved revision. Preserve or recheck relative links; adapt the parent-catalogue link for standalone distribution.

## Preserve meaning

Retain units, fictional labels, approximation dates and model limits. Distance markers are not object diameters. The address diagram means membership; the motion sketch does not specify real orbits; the sample light curve is not a continuous observation.

If you change numerical values, update the lesson, figure, answer key and rubric together and verify them again. Do not join the final project's separate exhibits into a single invented astronomical discovery.

Retain text equivalents and readable labels. SVG files allow adaptation, while PNG files support ordinary Markdown viewers. Do not substitute an unlabeled generated photograph or remove an “illustration” caption.

## Audience and hosting

The reviewed audience is adults 18+. Child-facing adaptations, optical activities, observation instructions or decision tools require their own suitability review. No fieldwork or solar viewing is included.

These static files implement no accounts, analytics or learner-data collection. Assess the actual hosting application separately; the files cannot establish that a host collects nothing. Added AI interactions or data processing fall outside this static package.
