# Exploring the Cosmos — glossary

[Course home](README.md)

| Term | Meaning in this course |
|---|---|
| Arbitrary unit | A unit defined for a supplied exercise, without an assumed conversion to a physical unit. |
| Axis | A reference line about which rotation is described. |
| Baseline | A stated reference level used for comparing a signal. |
| Dark energy | Name for the unknown cause associated with accelerated cosmic expansion. |
| Dark matter | Matter inferred through gravitational evidence; its physical nature remains unresolved. |
| Dwarf planet | Solar-system category distinct from planet, including Pluto; see lesson 4 for the limited definition discussed. |
| Electromagnetic spectrum | The range of electromagnetic radiation, including visible light and wavelengths our eyes cannot detect. |
| Exoplanet | Planet outside our solar system. |
| Galaxy | A gravitationally bound system containing stars and other material. |
| Habitable zone | Range of stellar distances where surface liquid water could be possible under suitable planetary conditions, not proof of life. |
| Hypothesis | An explanation proposed for testing. |
| Inference | An interpretation drawn from evidence and assumptions. |
| Light-year | A distance, based on light travel in vacuum over one year. |
| Main sequence | A stellar stage with hydrogen fusion in the core. |
| Model | A selected representation for a purpose; its assumptions and omissions matter. |
| Natural satellite | An object naturally orbiting another body; commonly called a moon. |
| Observation | A recorded result; records still need checks for measurement limitations. |
| Orbit | Motion around a body or shared centre of mass. |
| Percentage drop | Difference from the stated baseline, divided by that baseline, multiplied by 100. |
| Rotation | Turning about an axis. |
| Scale | The relationship between a represented quantity and its drawing or model value. |
| Solar system | Our Sun and the bodies associated with it. |
| Spectrum | Light separated or represented by wavelength. |
| Speculation | An idea without sufficient support in the evidence under discussion. |
| Transit | Passage in front of another object from the observer's viewpoint; planetary transits can reduce received starlight. |
| Uncertainty | A limit on how precisely or confidently a result can be established. |
| Universe | The wider physical cosmos; a labelled box does not define a measured edge. |

These are introductory explanations, not complete technical definitions for specialist work.
