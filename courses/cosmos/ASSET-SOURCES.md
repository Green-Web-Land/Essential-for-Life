# Exploring the Cosmos — illustration provenance

[Course home](README.md)

Five original diagrams were code-authored with AI assistance, each supplied as SVG and PNG. No third-party photographs, mission imagery, logos or figures are embedded.

| Files in images/ | Representation and limits |
|---|---|
| address.svg / address.png | Membership chain, not measured sizes, boundaries or distance. |
| scale.svg / scale.png | Fictional one-dimensional distance positions. Scale labels describe a paper model; screen display size may vary. Object markers enlarged. |
| motion.svg / motion.png | Circular orbit and rotation schematic; no speed or time scale. |
| spectrum.svg / spectrum.png | Invented line positions; no real wavelength or chemical identification. |
| transit.svg / transit.png | Fictional light samples. Joined points guide the eye, not a continuous measured curve. |

Text equivalents appear beside images. The transit plot uses a labelled narrow vertical range to make the supplied difference legible; it does not start at zero. Both its baseline and lows are shown numerically.
