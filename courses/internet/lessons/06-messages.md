# 6. Email and messages

[Course home](../README.md) · [Curriculum](../CURRICULUM.md)

**Learning goal:** Prepare a useful message while limiting unnecessary disclosure.

Email and messaging services deliver communication to selected destinations. An address or display name can be mistyped or misleading. Before sending, check the actual recipients, the purpose and the information included. A draft is not a sent message, and a “sent” indication does not prove that the recipient read or understood it.

To names the direct recipients. CC normally makes additional recipient addresses visible to other recipients; BCC normally hides BCC addresses from other recipients. BCC is not a confidentiality guarantee: people can forward, copy or disclose the message. Product behaviour varies; use the service's help if unsure. A group chat can also expose participants and history.

An attachment is a file sent with the message; a cloud link points to a resource whose permissions may change. Both can expose more than intended. Check the file itself, including hidden or overlooked personal details, before sharing. Do not send someone else's information merely because it was sent to you.

An unexpected urgent request for payment, credentials or a sign-in code deserves a pause. Verify through an independently established channel. Do not reply to the suspect message to establish its legitimacy.

## Worked example

Mina drafts a question about step-free access. Her draft includes the event name and the question, but no medical history or identity document. She verifies the organiser's address separately. In this course she leaves the message unsent.

## Try it — paper is enough

Fictional draft: “Please confirm access. Attached: our group's contact list and my ID.” Revise it to ask the event question with the least necessary information. Should you CC the whole group?

## Answer and reasoning

A concise event-specific access question needs neither attachment. Do not expose a group's addresses without a reason and permission. BCC may reduce address visibility in some situations but cannot make sensitive content safe to circulate.

## Use it somewhere else

Write an unsent two-sentence question using a fictional recipient label on paper. Check purpose, recipients and attachments before calling it ready.

## Sources and limits

This is general communication guidance, not a tested email-client walkthrough. No message or attachment needs to be sent.
