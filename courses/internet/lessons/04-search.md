# 4. Search with a clear question

[Course home](../README.md) · [Curriculum](../CURRICULUM.md)

**Learning goal:** Refine a search and treat results as leads to evaluate.

Before searching, write the question you need answered. “Library” is broad; “Saturday repair workshop organiser start time” identifies a task. Add a place, date or exact phrase when it matters. Try different ordinary words if the first query misses the subject. Search features and filters vary; no special syntax is required here.

A results page is a selection produced by a service. It can mix advertisements, page extracts and generated summaries. Position is not a certificate of authority. A snippet can omit context or reflect an older page. Open the underlying source, when appropriate, and check whether it actually answers your question. An AI-generated answer also needs supporting sources checked.

Avoid putting private account numbers, passwords or another person's sensitive story into a search query. Search services receive queries; minimising identifying details is a useful first choice.

When looking for an organisation's contact details, a convincing result can still be an impersonation. Prefer a previously verified official route and compare the organisation's own contact information. If you cannot establish it, leave the answer uncertain instead of choosing the most prominent result.

## Worked example

Mina searches for an event's time. One card advertises “priority access”; another is the organiser's dated notice; a third is an old discussion. She chooses to examine the dated notice first, then checks for later updates.

## Try it — paper is enough

On paper, improve “help Internet”. The fictional goal is learning the difference between Wi-Fi and Internet access, without troubleshooting a real account. Explain why your query is more useful.

## Answer and reasoning

For example, “difference between Wi-Fi and Internet connection” names the concepts. Many answers are acceptable. A useful query matches the question and excludes private details; it does not guarantee good results.

## Use it somewhere else

Optional: on a device you are permitted to use, search a harmless general question. Record a result type and its source, not your browsing history. Paper alternative: classify the three cards in the example.

## Sources and limits
