# Internet glossary

[Course home](README.md)

| Term | Meaning in this course |
| --- | --- |
| Account | A service identity with associated access or activity. |
| Attachment | A file included with a message. |
| Authentication | Checking a claim to an identity, such as at sign-in. |
| Authorisation | Determining what an identity may do. |
| Backup | A retained copy and recovery arrangement intended to restore information; recovery needs checking. |
| Browser | Software for accessing web resources. |
| Cache | Stored material that may be reused instead of fetched again. |
| Cloud service | Computing or storage provided through remote systems. |
| DNS | The Domain Name System, which helps resolve names to service information. |
| Domain | A name within the Internet's naming system; familiar words alone do not verify an operator. |
| Download | Transfer from a remote system to your device. |
| Host | The addressed system name or address within a URL. |
| HTTPS | A web connection protocol using encryption; not a guarantee of honest content. |
| Internet | Interconnected networks used to exchange data. |
| Link | A reference to another resource; its label and destination can differ. |
| Local network | A network connecting devices within a limited setting, such as a home. |
| MFA | Multi-factor authentication: additional identity checks using different factors. |
| Permission | Allowed access or action, such as viewing or editing a file. |
| Primary source | A source reporting its own activity or original material; still open to scrutiny. |
| Private browsing | A browser mode limiting some locally retained activity; not anonymity. |
| Query | A search question, or parameters in part of a URL; context determines which. |
| Request / response | An exchange in which a client asks a service for something and receives a reply. |
| Search engine | A service that helps find information; results still need evaluation. |
| Server | A computer or service responding to requests. |
| Synchronisation | Keeping selected locations in step, potentially including deletions. |
| Upload | Transfer from your device to a remote system. |
| URL | An address identifying a resource. |
| Web | Resources accessed through web protocols; one use of the Internet. |
| Wi-Fi | A wireless connection to a local network; not proof of Internet access. |

These are introductory explanations. Real systems have additional details; see [Sources](SOURCES.md).
